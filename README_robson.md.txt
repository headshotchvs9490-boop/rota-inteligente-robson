# Rota Inteligente

Projeto de Inteligência Artificial para otimização de rotas e agrupamento de entregas.

## Objetivo

O projeto utiliza Inteligência Artificial para organizar entregas e encontrar agrupamentos de rotas de forma mais eficiente.

## Tecnologias utilizadas

- Python
- NumPy
- Scikit-learn

## Estrutura do projeto

- `src/` — código principal do projeto
- `data/` — dados utilizados pelo projeto
- `docs/` — documentação
- `requirements.txt` — bibliotecas necessárias
